# 简历与工作台功能

AI 提案确认与自动保存共用写入队列，保存失败不继续确认。确认期间目标编辑器和样式设置暂停编辑，成功后从服务端响应同步当前正文；该操作不新增可恢复历史版本。创建、导入、复制和翻译同样只产生当前简历，不再创建历史版本。

## 功能范围

简历功能覆盖模板创建、文件导入、编辑与自动保存、独立复制、模板切换、资源、分享和 PDF 输出。浏览器维护编辑中的交互状态，服务端当前简历是持久化权威数据。

具体 schema、稳定错误和并发冲突见 [HTTP 接口契约](../api/http-contracts.md)，编辑器视觉与交互基线见 [Web 架构](../internals/web.md)。

desktop 渠道获得模板、本人简历、PDF 和私有图片的明确 GET 权限，以及从模板新建、重命名、复制、删除和分享链接管理；复用现有归属、版本和复制幂等校验，以及 canonical 正文与版式样式保存、模板切换（`POST /api/resumes/{id}/apply-template`）和简历图片上传/删除；语义分类与 legacy `/api/assets` 上传仍不开放；完整白名单见 [桌面会话契约](../api/http-contracts.md#桌面-bearer-会话)。Mac 登录后读取真实模板列表并可从模板创建简历；“我的简历”使用列表摘要预览本人简历，支持按 `lock_version` 导出 PDF、重命名、复制、分享与删除，并提供原生结构化编辑器：文字格式（加粗、斜体、下划线、删除线、代码、字号、颜色、背景色、链接、图标）、段落对齐、列表、分栏行、图片与头像、模块类型与顺序、模板切换、字体字号行距边距与智能一页，纸面按本地编译的版式计划实时预览，详见 [原生客户端](../../apps/native/README.md#mac-我的简历)。

## 用户入口

- `/resumes`：简历卡片列表，标准桌面宽度为四列；页头的导入与新建操作使用共享胶囊形按钮，分别带上传和加号图标，按钮宽度由内容与内边距决定，不固定宽度。创建、导入、重命名、复制、删除和分享均有独立弹窗，加载失败显示重试入口。
- 没有简历或搜索无结果时，使用与其他模块相同的居中空状态卡片，桌面宽度为 520px，窄屏按可用宽度收缩；空状态不随简历网格铺满内容列。
- `/resumes/new`：从启用模板创建简历。
- `/resumes/:resumeId/edit`：正文编辑、页面设置、模板切换、AI 侧栏和 PDF 导出；生产构建暂不显示打开 AI 侧栏的悬浮入口。 顶栏右侧仅保留完整度检查与 PDF 导出按钮，不提供三点菜单或删除简历操作；删除简历在简历列表进行。
- `/assistant` 右侧简历预览复用正文编辑与自动保存，独立编辑器工具栏不进入内嵌模式。发送前保存脏草稿，当前简历和选区按既有上下文协议提交；应用提案后回读并刷新当前简历。
- `/templates`：模板浏览与预览，页头右侧提供“筛选”按钮，卡片紧接页头展示且不再显示模板数量摘要；点击“筛选”展开下拉层，可按视觉风格（简约、经典、现代、创意）和适用场景（实习、校招、社招）分别多选，点选后立即应用；同组匹配任一标签，跨组同时满足。卡片展示已标注标签，没有结果时可清除筛选。模板按管理员设置的展示顺序升序排列，相同排序值按模板 ID 排列。编辑器切换模板侧栏复用同一套分类筛选和展示顺序。卡片缩略图是整份 A4 简历按真实尺寸排版后缩小的，只有进入或接近视口的卡片才真正排版渲染，卡片尺寸由外层宽高比决定，滚动高度和最终排版结果不受影响。
- 默认目录在迁移 `0081` 后包含 85 套启用模板，已下架经典单栏、现代双栏、紧凑技术型三套废弃设计。其中 Atlas 系列提供 37 套排版，Studio 系列提供六套卡片、双色分区、肖像、胶囊与时间轴样式。新增 Open 系列六套 MIT 授权排版，来源见[模板授权记录](../internals/resume-template-sources.md)。Original 系列包含朱砂编辑笺、横向分庭、墨绿档案签、横轴履历、暖灰书页、非对称索引、错位页眉、折页边注、悬挂章节九套经图像设计确认的原创模板。Career 系列新增青墨财务档案、橙标精益履历、留白师范履历、细线护理履历与蓝线传播履历，分别覆盖财务、制造业社招，教师、护理校招和市场营销实习；校招、实习突出教育与实践，并标明预计毕业和资格状态。各模板使用虚构示例内容；创建时保存模板快照，后续目录更新不覆盖已有简历。Featured 系列包含蓝幕校招、浅蓝社招、清蓝实习、钴蓝右栏、蓝色拼版、蓝线财务和蓝带人事，并增加卡片虚线、卡片分栏、经典商务与活力四套版式；已有的分层胶囊章节、节点时间轴不重复新增。
- `/share/:token`：受可见性与过期时间约束的只读分享页。
- 管理端 `/admin/templates`：严格模板包导入、卡片网格缩略图和完整预览、启停及拖动调整展示顺序；缩略图与用户模板库复用同一只读渲染器，结构无效模板显示占位。排序值越小越靠前，相同值按模板 ID 排列。迁移 `0087` 仅在没有人工排序值时按原有 ID 顺序将存量模板初始化为 10、20、30……；新导入模板取当前最大排序值加 10（上限 1000000）。管理员可以一次提交全部模板的新顺序，服务端在同一事务中按列表把排序值重写为 10、20、30……；提交的列表与当前模板集合不一致时整体拒绝，已有顺序不变。模板详情弹窗供管理员逐套查看结构有效的模板，可为一套模板分别多选视觉风格与实习、校招、社招适用场景，或将风格标记为待讨论。分类通过管理员接口写入模板表并同步到用户模板库，也可导出按模板 key 标识的 JSON。详情弹窗左侧预览与右侧设置面板分别滚动，右侧底部提供删除操作，二次确认后才执行；只有未被任何简历或导入任务使用的模板可以删除，已被使用的模板提示改为停用。迁移 `0085` 为当时的 85 套启用模板写入初版标签；之后的调整以数据库为准，新导入模板默认未分类。

简历列表、重命名与导入弹窗、独立新建/导入页、模板创建弹窗和编辑工作台的操作异常统一通过页面根层在视口上方居中提示，不受业务弹窗或卡片定位影响，并在 3 秒后自动消失；编辑器中的字段校验仍保留在对应表单附近。

编辑器使用无侧栏整窗，顶部提供返回、撤销/重做、标题与保存状态、评分、更多和导出 PDF；右侧工具轨打开大纲、模板、排版和简历检查。排版面板标题为“设置”，依次包含上下/左右排列与智能一页卡片、页边距、字体、字号与行距；原底部页面栏不再显示，全部页面控制移入右侧。页边距、字号和行距使用加减步进按钮，保留原有参数范围与保存行为；模块顺序仍在大纲中调整。大纲的左右栏标签按模板中实际呈现位置显示，右侧侧栏不会再标为左栏；分组按左栏在上、右栏在下展示，各栏内部模块顺序不变。编辑器打开失败使用独立错误页，能重试或返回全部简历。模板卡片与预览显示接口返回的真实使用次数（引用该模板的简历数，千以上写作 3.2k），选中的模板卡片与模板筛选项使用蓝色选中态而非黑色，真实保存、模板切换、分享权限及 PDF 仍由现有 API 决定。当前界面不展示历史版本比较或 Pro 功能。

简历和模板网格按可用宽度自动改变列数，窄屏页头操作换行。编辑器按实际画布宽度适配预览，手机工具轨位于底部、面板覆盖画布；模板预览弹窗的纸面按舞台宽度等比适配，并保留手动缩放。规则与打印边界见 [Web 响应式布局](../internals/web.md#响应式布局)。

编辑器按固定 A4 尺寸计算文字换行与分页，显示缩放使用 CSS `scale`，外层占位容器同步缩放后的纸张宽高。上下与左右排列复用相同分页占位；左右排列在模板内容外按单页宽度分栏，保留模板内部网格、侧栏与正文宽度，页面依次显示为“页 1 ｜ 页 2”。切换排列、自动适配、手动缩放和窗口尺寸变化只改变纸张的显示位置与比例，不改变内容的分页归属。

模板库只挂载可见区域附近的完整预览，滚动远离后释放，卡片名称、标签、顺序和占位尺寸仍保留；宽度拖动期间复用纸面绘制缓存，停止后恢复最终比例的清晰渲染。

选区浮动工具栏使用根层共享产品字体 Token，挂载在纸张外时仍沿用产品界面字体；简历正文继续由模板和用户保存的字体设置决定。

## 核心对象与规则

- `resumes` 保存当前 canonical 内容、呈现、模板、分享状态和 `lock_version`；保存和模板切换必须通过乐观锁。正文只保存模板无关的 identity、语义章节、块、章节内 row 和来源引用，不能保存 sidebar/main、CSS 或分页投影。
- `0089` 已移除 `resume_versions` 和全部旧版本接口；旧历史快照不再提供读取、恢复或复制取回，当前简历保存在 `resumes`。
- `resume_templates` 保存 `TemplateDefinition` 与默认 canonical 内容；普通用户只消费启用且结构有效的模板。模板拥有区域、插槽、列宽和头像显示策略，`LayoutPlan` 是后端编译的只读投影结果。
- 新增 Muse 模板展示名采用 4–6 字、贴合配色和版式的中文名称，由 `resume_templates.name` 提供；稳定 key 与简历中的模板快照独立于展示名称。当前名称与旧名见[模板名称对照](resume-template-names.md)。
- 内置模板的默认虚构示例按原有字号与版式尽量控制在一张 A4 内；示例精简只影响模板预览与之后新建的简历，已保存简历继续使用自身快照。用户填写更多内容后仍按原有规则分页。种子更新的保护规则见[一页模板示例迁移](../internals/backend.md#一页模板示例0103)。
- Web 默认简历中的图片占位标签使用随应用发布的霞鹜文楷；它只负责示例占位图呈现，不覆盖用户保存的简历字体设置。
- canonical 正文把白名单内的简历图标保存为结构化 `InlineIcon`，章节标题使用独立 `title_icon`；`:icon[Name]:` 只作为 Markdown、Agent 和旧数据兼容边界的序列化形式，不能作为预览中可见的普通正文。未知或不完整标记继续按原文字保留，避免静默改写用户内容。
- 简历图片在进入当前快照前统一校验 PNG/JPEG 格式、单图 10 MiB 上限和快照引用总量 10 MiB；不满足条件时保存、模板切换、复制和 Agent 提案确认均明确失败，避免延迟到 PDF 导出阶段才暴露问题。
- 用户确认整篇翻译提案时会创建一份独立可编辑简历，原简历不变。账户级图片继续共享；源简历专属图片复制到新简历命名空间并改写引用，复制或事务失败时不保留半成品简历。
- canonical 列表保留用户创建的空项，空项使用 `runs: []` 表达，不写入空格或占位文本；列表块本身仍至少包含一个列表项。
- 列表项转换为左右分栏时，先在同一未提交事务中提升列表项，再生成分栏行；全部成功后一次提交并支持一步撤销，转换失败不保留部分提升结果。
- Web 编辑器在可容纳列表的普通段落行首输入 `-`、`*` 或 `+` 加空格时创建无序列表，保留隐藏定位锚点，并合并相邻的无序列表；正文中的减号、负数和年份范围保持普通文本。数字与无序列表回车续项后，空项按退格或再次回车会退出一层列表结构，保留当前空白段落和光标；顶层退出后再按退格才删除空行、返回上一行，嵌套列表逐层退出。
- 标题行首按回车在标题上方插入空段落而非拆出空标题，光标留在标题行首；文本块行首按退格时若上一块是空行则删除空行、当前行类型不变，若是标题且上一块有内容则并入上一文本块；空行内按 Delete 删除该空行并把光标落到下一行行首。行首判定把隐藏定位锚点前后的停靠位都算作行首。编辑器内中文输入法组合期间，命令面板与分栏栏数菜单不响应按键，分页测量也推迟到组合结束后再派发。个人信息按 canonical 锚点角色区分职位描述和联系方式，编辑器与预览、分享、PDF 统一使用 `resume-identity-headline`、`resume-identity-contacts` 标记；缺少姓名或职位描述、插入空行或移动到侧栏时，联系方式仍使用目标模板的联系方式样式。无语义锚点的历史编辑内容保留一级标题后首个非空段落作为 headline 的兼容识别。
- `document_parse_tasks` 保存简历导入和资料集共用的上传/解析状态，`file_format` 约束覆盖文档四类和音视频七类（媒体任务不使用解析队列，直接落终态）。简历导入在受理时同时冻结 `selected_template_id` 与规范化的 `selected_template_style_json`（完整 `TemplateDefinition`），并把确定性的 `SourceGraph` 保存到私有对象；Worker 只使用任务快照，因此模板之后更新或停用不会改变已受理任务的版式。资料集任务额外使用 `queued`、派发时间和尝试版本完成 MQ 恢复。PDF/DOCX 由 LinkParse 转换文字并可附带有界布局提示，Markdown 在 Worker 本地转换。PDF 始终使用 `include_images=false`：文字与图片混排的 PDF 继续解析文字，但证件照、Logo 和其他源图片不会进入导入结果，模板头像保持为空。
- 分享实时读取当前已保存草稿，不另存内容快照；PDF 同样使用当前已保存快照生成且不持久化成品。

- 模板创建、导入解析成功、复制新建（幂等重放不算）和翻译提案确认会在同一事务内写入 `resume_created` 产品漏斗事件；本人网页与小程序 PDF 导出成功后以独立短事务写入 `resume_pdf_exported`，写入失败不影响 PDF 响应，分享页访客下载与小程序预览图不记录。口径见 `docs/internals/observability.md`。

## 依赖边界

该功能依赖身份、MySQL、MinIO、Redis、消息队列、LinkParse 和统一 LLM。求职进程保存独立的投递附件；AI 助手只能先创建提案，用户确认后才写入简历。删除简历时清理目标为该简历的待确认提案，但保留独立对话历史，且不能越过其他领域的引用约束；关联的模拟面试只清空简历引用，保留简历快照与报告。

删除简历时，同一事务会一并删除该简历与各岗位的匹配结果；简历内容变化会使已有匹配结果过期，只改标题或排版不会。

## 关键流程

### 创建与编辑

命令面板会用强调色标出光标所在行真实的块类型（正文、标题 1–3、列表、左右分栏）；已有正文行或列表项都可以直接转换为左右分栏，原文字放在最左栏；左右分栏支持两侧独立输入，光标位于分栏行内时再点一次“左右分栏”即可取消分栏、合并回普通正文，也能用退格删除已经清空的分栏行；右键分栏行可切换为 3 栏或 4 栏；3/4 栏默认等分；光标位于分栏行内时，2/3/4 栏均可拖动栏间分隔线调整宽度，双击分隔线恢复等分，改栏数后重新等分。2 栏沿用 30%–80% 的左右比例，3/4 栏仅调整相邻两栏且各栏至少保留 10%；调整结果保留在正文快照中，保存、模板切换和导出继续沿用既有排版规则。光标落在分栏行内时，还没有可见内容的栏显示“左侧内容…”“右侧内容（日期、地点等）…”这类编辑提示，3/4 栏的行只在首栏提示“每栏独立输入…”；该栏一旦有文字、图标或图片就不再提示，提示本身只用于编辑，不进入保存内容、分页和导出。分栏与其他区块中的图片、图标等可选中叶子节点支持鼠标点选为节点选中，便于剪切复制；按住从这类节点拖动时选区锚点固定在节点自身边界，行内原子可按拖动方向扩展覆盖相邻文字，块级原子拖动时保持节点选中、不扩展进周边文字，从文字拖入这类节点且端点落在其上时选区恰好覆盖该节点。选区跨越多个段落并覆盖某个分栏/布局节点的全部内容时，复制与剪切携带整个结构节点（只在一栏内选字时始终按文字处理，即使其余栏为空）：剪切会连结构一起移除、不在原地留空壳，粘贴到别处能还原分栏排版；编辑器内部剪贴板（带 data-pm-slice 标记）粘贴时保留节点结构，外部来源 HTML 仍拍平为纯段落。栏数固定的行（左右分栏行、三栏/四栏等分行、页头三行与四行）内按回车不在行内分段，而是统一退出行并落到紧随其后的空白段落，行后已有空白行时不重复插入；退格可删除这个退出产生的空白行并回到行末格。光标或选区落在分栏行、页头三行/四行内时，该行为浅蓝激活外框；选区完整覆盖某个布局节点（分栏行、页头行或整组分栏）的全部内容时，外框落在该节点本身，提示即将被整体剪切复制的结构。栏容器与普通段落不显示常态外框，避免正文区域整片染色。

可编辑画布使用浏览器原生细光标，并沿用所在文字的颜色：浅色区域为深色光标，深色区域为浅色光标；不再插入额外光标装饰或遮挡文字。中文输入法组合输入也使用同一原生光标。

头像默认按一寸照约 25×35mm 的竖向比例展示（画布宽约 94 CSS px），普通模板保持方角或轻微圆角；明确使用圆形或拱形肖像的模板保留 1:1 裁切。选中头像只显示细描边，不改变照片形状；按住 ⌘/Ctrl 滚轮调整宽度时同步保持当前模板的纵横比例，已手动调整的尺寸在模板投影中保留。打印和只读预览采用同一尺寸规则。

行内图片选中时叠加轻量遮罩和描边，并在图片上方显示固定锚定的尺寸工具条。工具条只展示当前宽、高数值及各自上下排列的增大/减小箭头，每次调整 1px，结果限制在 16–240px；不提供尺寸文字输入或替代文字重命名。尺寸变化后图片保持选中且工具条位置不随宽高移动；再次单击普通正文会解除图片节点选区，并把文本光标放到实际点击位置。

选中文字后，浮动工具栏按粗体、删除线、斜体、下划线、链接、字体、本行类型、对齐方式排列，块级的两项与前面的内联格式之间用竖线分隔，下拉统一向下展开。「链接」为选区填写网址，选中已有链接时可取消，并沿用简历规则拒绝把邮箱或 `mailto:` 设为链接；「本行类型」在正文与标题 1–3 之间切换当前块，二级标题是章节锚点，改成其他层级会让该块失去章节语义；「对齐方式」设置当前块的左 / 中 / 右对齐，并随正文保存，刷新、只读预览、分享与 PDF 都使用同一对齐；切换模板时，姓名、职位描述和联系方式恢复目标模板的默认对齐，正文手动格式保留；联系方式行整行共用一个取值，行内首个非空联系方式决定方向。「字体」弹层把字号、字体颜色和背景颜色收在一处：字号沿用 6–48 pt、0.5 pt 步进的数值控制，未覆盖时显示模板或全局排版的实际数值，混合选区显示“混合”并以首字字号为基准统一调整；字体颜色以文字颜色本身渲染色板，背景颜色为两行色块，两者都用斜杠表示“取消”，并可一键恢复默认。列表、缩进和「AI 修改」不出现在选中弹窗，撤销 / 重做仍是编辑器顶部左侧的常驻按钮（无可撤销内容时置灰）。浮动工具栏随画布缩小同步变小，画布放大到 100% 以上时保持基准尺寸，不再跟着放大。支持单字、跨段落、姓名、章节标题、联系方式、经历字段、列表及分栏正文；局部字号与文字对齐随当前快照保存，并用于只读预览、分享与 PDF；模板切换仅重置个人信息的文字对齐。

1. 创建时校验用户额度、名称和启用模板，在同一事务写入当前简历。
2. 编辑器根据当前 `LayoutPlan` 把 canonical 内容投影为可编辑视图。页面设置面板只提供页面排列、模块顺序、上下与左右边距和正文排版；模块顺序只改变章节先后，不改变章节语义，语义仍随 canonical 内容保存，也不在该面板中手动调整。选中文字后的格式浮层锚定在选区最后一个字的右下角，浮层尺寸与间距跟随当前画布缩放，并在滚动、缩放或视口变化后重新定位。正文和页面设置先同步更新前端 Store 并立即作用于画布，边距预览不等待数据库保存完成；未写回数据库的修改按用户和简历隔离保存为浏览器本地草稿，在重新载入相同 `lock_version` 时恢复。数据库自动保存按 10 秒固定节拍检查脏状态，先反投影为 canonical 文档再串行发送 `base_lock_version`，不因每个字符或单次页面设置调整单独请求；成功后接续服务端新锁版本，工作台页头不再提供手动保存按钮。
3. 模板切换先在前端清除个人信息的文字对齐覆盖，再把当前标题、canonical 内容、目标模板和锁版本一次提交；不改变文字、联系方式、正文格式和头像内容。服务端校验切换前后正文摘要一致，只替换模板身份和 presentation，并在同一事务递增一次锁；头像仍属于 identity，模板只决定是否和在哪里展示。

### 段落聚焦

编辑器不在顶栏放 AI 按钮。用户有三种方式唤醒段落聚焦：
- 光标停在一段经历里时，这一段外出现蓝色虚线框，框的下边线贴着一条与框同宽的指令条：左侧是蓝色「聚焦这段」，后面是一行输入框，直接写要求按回车即可带着要求聚焦，输入框为空时下方给出常用要求。下方放不下时指令条移到框的上方。正在段落里打字时指令条暂时隐藏，停下约 1 秒后重新出现；指向指令条或在其中输入时，虚线框变为实线并加深底色。框不接收点击，点击指令条（输入框除外）不会让光标离开简历；指令条会遮住框下方的少量文字，点到那里时光标移走，指令条也随之移到新段落。
- 画布缩放时，框和指令条先隐藏，缩放停止约 140ms 后按新的比例重新测量位置；指令条随缩放缩小到 85% 为止，放大超过 100% 时不再变大。
- 按 ⌘K / Ctrl+K 打开一句话面板。光标所在的段落是默认目标，直接回车即可聚焦；句子里点名了另一段时，在前端按公司、项目和段落标题本地匹配目标段落：
  - 唯一命中时显示「AI 理解为：目标 / 要求 / 风格」（风格显示默认的 STAR 法则），用户确认后才开始；
  - 没有命中或有多段命中时，列出候选让用户点选。

入口第一次出现时在页边给出一次引导（页边放得下时），记录在浏览器本地。段落左侧的被动提示点暂不提供：现有完整度检查不按段落给出结果。

**段落划分**：聚焦的单位是一段经历（一份工作、项目或学校）；没有分条目的段落（如技能）以整个分区为单位。
- 没有条目结构、用表头行（时间｜公司｜角色｜标签）分隔经历的简历，每个表头行和其后的要点各成一段，同一分区里的两段实习不会合并。表头行按节点类型（`resumeRow`、`resumeMetaRow`、`resumeTrioRow`）识别，不依赖锚点上的 `row` 角色。
- 多段经历放在同一个无标题条目里（分区标题下只有一行空的条目标题）时，也按表头行拆开：第一段沿用这个条目，标题取表头里的公司名；后面每遇到一个表头行，只要前一段已有正文，就另起一段。
- 没有表格行、只用一行普通文字写表头的简历，如「2023.06 - 2023.09  公司  职位」或用「|」「·」分隔，同样当作表头。判断条件：含起止日期，不超过 80 字，不含句号、逗号、分号等句子标点。起止日期支持「2023.06」「2023-06」「2023/6」「2023年6月」、只写年份的「2019 - 2023」、英文月份「Jun 2021」，结束可写「至今」「Present」。
- 以上规则不区分分区：教育、科研、项目、工作、实习等分区里的多所学校、多个课题或多段工作都按同样方式拆开。前一段即使没有正文，只要两行表头各带起止日期（如两所学校连写），也拆成两段。
- 表头上一行单独写的短名称（不超过 40 字、无句子标点、不以冒号结尾、不是日期），如课题名或学校名，作为这一段的标题，不留在上一段末尾；只有它正好是上一段的最后一行、且与表头之间没有其他内容时才这样处理。
- 拆分只发生在聚焦的段落划分中，全自动、不改动简历保存的条目结构。
- 条目标题下的日期、学历、职位等短信息归入表头展示，不作为待改写的句子；只剩这些信息时仍按正文处理。

**聚焦稿纸**：开始后，这一段被抬到稿纸上：
- 顶部以经历名称为标题，日期靠右，职位等信息在下一行。
- 同一分区有多段经历时（如两段实习），标题前有序号，顶部写「实习经历 · 第 1 段，共 2 段」，标题下列出同分区的其他经历（序号、名称、日期），点击即切换。左侧目录中这些经历也带序号和日期。
- 左侧是按分区分组的全文段落列表，可以切换段落；名称最多显示两行，当前段落为白底并带蓝色左边线。
- 顶部第二行用「以 [风格] 分析，投递 [岗位]，突出 [方向]」设置三项，互相独立。分析风格必选，有 STAR 法则（默认）、XYZ 公式、CAR 法则和通用写作标准，每项下方一行说明；投递岗位选填，默认「不指定岗位」，菜单打开时才读取本人已收集的岗位，选中后在所选风格之上按岗位要求分析；AI 推断的方向显示为输入框的占位文字，需要用户点「就按 AI 推断」才生效。
- 同一行右侧的「一并参考」把要一起发送的其他段落收成一个下拉菜单（显示「某段 等 N 段」），在菜单里勾选，默认最多 6 段。
- 稿纸里的下拉、输入框不使用全局蓝色聚焦框；底部输入栏获得焦点时只加深边框。
- 分析进行中，批注栏顶部（与段落标题同行）出现一条蓝色左线的进行中批注：「AI 正在分析」和跳动的三点，下面是按时间更替的一句话（通读这一段 → 对照其他 N 段经历 → 对照所选风格（选了岗位时连同岗位） → 整理批注，只用于提示节奏，实际是一次请求），再下面是已等待秒数和「通常 10–30 秒，完成后批注会出现在这一栏」（超过 25 秒改为「比平时久一些」）。正文各行变浅，阅读光标约每 1.1 秒移到下一行，当前行恢复深色、项目符号变蓝放大；前 3 条可改写行的批注位显示两道细骨架线；稿纸页眉下边线有一道流动的细光。底部输入栏提示分析完成后再提要求。系统要求减少动态效果时停用这些动画。

**批注与修改**：分析结果以页边批注展示，问题词句用荧光笔标出：橙色 = 缺信息，蓝色 = 表达，紫色 = 结构。
- 缺信息：逐题追问，回答后生成句子。
- 表达：给出改写，用 A/B 选择。
- 结构：给出只改本段的跨段提案。
- 用户还可以在稿纸底部用一句话提出要求（例如「第 2 条写得更有冲击力，但别夸大」），针对某一句生成版本。
- 比原文说得更重的词会单独提示，需要用户确认属实。

改动用统一颜色表示：绿色底 = 新增或改写的文字，灰色删除线 = 删掉的原文。稿纸底部只占一行：「原文未改动 / 本段改动」、「已处理 N / 总数」和快捷键提示；逐条的状态只在批注栏显示。

**写入与撤销**：
- 采用前先比对这一句的当前文本与生成时的文本，不一致时不写入，标为已过期并提示重新分析。
- 写入只替换该句的可见文字并保留定位锚点；该句原有的行内格式会按纯文本替换。
- 写入后走现有的自动保存。
- 超过 500 字或不在前 20 条里的句子不会完整发送，AI 不改写这些句子，稿纸上会标注。
- 重新分析使用当前页面上的最新文本；已采用的改动保留在清单里，仍然可以撤销。
- 每段只在第一次进入时自动分析。分析结果连同建议状态、风格、岗位和上下文按段保存在当前页面内；退出后再进入或在目录里切回来时直接复用，不再调用模型。离开页面或切换简历后清空。
- 聚焦详情顶部的「重新生成」按钮会重新分析这一段。从 ⌘K 带着新要求进入时也会重新分析。如果这段在上次分析后被改过（不算在这里采用的改动），顶部会提示建议重新生成，但不会自动重跑。
- 已分析过的段落，结果按岗位透镜的样式显示在简历页面上：
  - 有问题的句子在页面左侧留白里有一条色条（橙 = 缺信息，蓝 = 表达，紫 = 结构，绿 = 已采用），问题词组用同色荧光笔标出。荧光笔使用 CSS Highlight API，不改动编辑器内容。
  - 页面右侧页边按段落列出建议卡片，用连线接到对应句子；卡片显示标题、说明和状态（待处理 / 已采用 / 已跳过 / 原句已改动）。点卡片直接打开这一段的聚焦稿纸并定位到这条建议，不重新调用模型。
  - 只要本页有分析结果，桌面宽度（≥981px）下画布右侧就为分析栏让出固定一栏，纸面在左侧剩余区域居中；放大到纸面超出可视区域时纸面在左侧横向滚动，分析栏仍完整显示。打开大纲、检查等右侧面板时不让出这一栏，右侧页边放不下时只显示色条和荧光笔。每段经历的分析各自「收起」：收起后在页边与这段经历第一行对齐的位置留一个标签，显示经历名和待处理条数，点它只展开这一段；重新分析这段后自动展开。聚焦稿纸或回顾卡打开时不显示。
- 复用时以当前文本为准：上次采用、但之后在回顾卡里撤销或手动改过的建议，会回到待确认状态。上次已经在回顾卡中展示过的改动，不再计入这次的回顾。

**放回**：按 Esc 或点「完成」后稿纸落回页面：
- 新增的文字短暂高亮后淡出；
- 旁边出现「这段改了什么」回顾卡，通过左侧列表切换过的其他段落的改动也一并列出；
- 底部提示条提供「查看改动 / 全部撤销 / 下一段」。

撤销只在当前页面会话内有效，并且只在该句仍等于改后文本时才恢复改前文本，刷新后不能再撤销。后端只做分析和改写，不保存修改记录。接口见 [HTTP 契约](../api/http-contracts.md#编辑器段落精修)。

### 导入与复制

1. 导入弹窗通过带可访问名称的原生文件输入支持点击选择和拖放，选择后展示候选文件并由用户确认名称；提交后在校验启用模板的同一受理事务中写入原件、导入任务、模板 ID 与完整模板定义快照，再发布消息，队列失败不会伪装成已受理。
2. Worker 根据格式选择本地 Markdown 转换或 LinkParse，把解析块与可用坐标统一成稳定 `source_id` 的 `SourceGraph`。结构化输入显式携带 `source_graph_sha256`，模型原样回传并遵守 Composer 的角色、字段闭集与条目锚点约束。LLM 只返回可选的稀疏语义增强，未标注源块由确定性组合器按来源顺序保留；结构化调用未配置、超时、供应商失败、响应无效或标注校验失败时记录脱敏 warning 并返回匹配该来源图的空标注，因此不会因增强不可用而让整份导入失败，也不会生成“未分类内容”。
3. 组合器把 canonical 内容注入任务冻结的模板定义，编译并校验 `LayoutPlan` 后，在用户行锁内分配导入标题：文件名 stem 已被占用时依次追加 `1`、`2`，再在同一事务创建当前简历并完成任务；任务快照缺失、模板身份不一致、来源图或布局任一不一致时不创建半成品。
4. 复制当前简历需要内部锁标记及请求 UUID；重试返回同一份副本。副本有独立标题、正文、样式和私有图片，不继承分享链接或导入任务。存量历史内容只能复制为新简历，不能恢复覆盖当前内容。

### 分享与输出

分享 token 定位简历主记录中的当前已保存草稿，并执行可见性、过期和所有者判断；自动保存成功后，公开页无需创建正式版本即可读取新内容，浏览器中尚未保存成功的本地编辑不会公开。公开响应把当前草稿引用的本人私有图片转换为受控 data URI，分享页因此不需要匿名访问私有资源路由；`private` 链接仍只允许所有者登录访问。分享页把当前草稿按 A4 分页并纵向排列，保留模板样式，不回写草稿中保存的智能一页设置；加载、正常内容和失效状态都固定使用浅色主题，不跟随访问者的系统深色模式切换。公开响应附带 `expires_at` 与 `updated_at`，分享页顶栏显示有效期（永久链接显示“长期有效”），页脚显示最后更新日期；私密、过期和删除仍统一按失效展示，不区分原因。分享页不提供浏览器打印入口；分享者允许下载时显示“下载 PDF”，下载沿用编辑器的服务端 Node/Chromium 渲染链路，按 A4 分页生成纯简历文档，不包含分享页头部和按钮。关闭下载后公开页隐藏入口，PDF 接口也对包括分享者本人在内的所有访问者拒绝下载，不能通过直接请求绕过。分享面板创建链接时直接使用当前选择，链接默认明文并可一键复制；已有链接的可见性、有效期和下载权限修改后立即保存，界面始终显示真实到期时间，仅重新生成和删除保留二次确认。面板根据管理接口状态判断可用性，不额外下载完整公开分享 payload。页面设置中的霞鹜文楷选项在编辑器、分享页和 PDF 导出中统一使用随应用发布的 Medium 字重，用户选择的字体保存在当前模板的 `template_scoped.font_family` 覆盖中，缺少覆盖的旧简历继续使用模板默认字体；简历图片只接受 PNG/JPEG，上传、公开分享与 PDF 导出共用 10 MiB 单图上限，当前快照引用图片总量也限制为 10 MiB，并在保存、模板切换和复制前校验。编辑器 PDF 先完成当前保存，分享 PDF 直接读取当前已保存草稿；两者都由后端读取受控图片、调用一次性 Node/Chromium 渲染器返回文件，打印 DOM 与浏览器只读预览共同消费同一快照和样式事实源，三处使用相同的霞鹜文楷字重。

移动端分享页把固定 210mm 的 A4 DOM 按滚动容器实际内容宽度整体缩放（CSS `zoom`，不支持时回退 `transform: scale` 并以缩放后高度占位）；`text-size-adjust` 抑制浏览器文字放大，微信 webview 再通过官方 `WeixinJSBridge` 的 `setFontSizeCallback` 把字号恢复标准档，避免字体放大撑破固定纸面造成重排变形。屏幕缩放只服务小屏预览，打印媒体下解除缩放仍输出原始 A4 文字版。响应通过 `assets` 字段内嵌渲染图片（data URI），匿名访问者可直接查看简历内图片（见 HTTP 契约）。

分享链接复制支持远程 HTTP 的 Dev 访问；浏览器仍拒绝复制时保留明文链接并提示手动复制，重试成功会清除错误提示。编辑器向助手提供选区时，HTTP 与 HTTPS 使用相同的 SHA-256 原文摘要。实现边界见 [Web 浏览器能力兼容](../internals/web.md#浏览器能力兼容)。

只读预览、分享与 PDF 保留正文连续空格；双栏与编辑器共用相同轨道比例、栏内间距和普通字形，不额外把右栏改为斜体。分栏单元格与列表项可各自保存左 / 中 / 右对齐，刷新、模板切换及只读输出均沿用；未设置时继续使用模板默认规则。行内图片的显式宽高优先，缺省高度按宽高比计算，编辑器、剪贴板与只读渲染共用同一尺寸计算。

### 完整度检查

评分前移除编辑器锚点及受控的局部字号、颜色、高亮和下划线标记，拼接连续的可见文字；改变单字或段落样式不会改变姓名、联系方式、章节识别和完整度得分。

工作台对当前实时 Markdown 运行确定性规则，覆盖姓名、电话、邮箱、职业定位、经历、教育、技能和基本结构，不依赖 API、LLM 或外部评分服务。技能检查只读取技能类章节正文，不从教育、工作或项目正文借用技术词加分；标题、空内容和占位文字不计分，条目数量与工具、熟悉程度或应用场景等具体程度分别计分。

1. `setEditorContent` 每次编辑都同步刷新当前 Markdown，评分无需等待自动保存或手动保存。
2. 顶部评分入口展示 0–100 分；点击后打开“简历检查”抽屉，逐项显示状态、得分、问题和建议。低于 40 分显示红色，40–80 分显示黄色，高于 80 分显示蓝色。
3. 系统示例身份按未填写处理并把总分封顶为 20，残留示例学校、公司或项目把总分封顶为 60。结果不评价整体表达质量或岗位匹配度，也不写入 Store 持久状态、API、数据库或版本。
4. 检查失败或低分不阻止编辑、保存和导出；切换简历后根据当前正文重新计算。

`0111–0115` 之后，简历相关表名为 `resume`、`resume_template`、`document_parse_task`，时间列为 `create_time`/`update_time`，分享下载开关列为 `is_share_allow_download`；接口仍输出 `created_at`、`updated_at` 和 `share_allow_download`。删除简历时，求职记录与模拟面试上的简历引用和匹配结果由服务显式解除或删除，不依赖数据库外键。详见[阿里巴巴 MySQL 规约整改](../internals/backend.md#阿里巴巴-mysql-规约整改)。

## 权限、并发与失败边界

- 所有简历、版本和资源操作同时校验 `resume_id + user_id`，不能仅凭资源路径授权。
- 乐观锁冲突、保存失败、模板无效、渲染失败或 Agent 提案冲突都保留客户端当前内容，不触发后续下载或部分写入。
- 私有图片只允许受控对象键和格式；PDF 渲染不联网读取正文资源，也不持久化输出。
- 删除简历、版本、模板或资源时必须先核对求职进程、分享、Agent 和对象存储影响。

## 修改联动与验证

修改快照结构时需同步 Python/TypeScript 契约、迁移、模板包、编辑器、预览、分享、PDF 和小程序预览；修改导入需同步 Worker、MQ、LinkParse、LLM 和开发/部署说明。主要测试入口包括后端 `test_resume_lifecycle.py`、`test_resume_imports.py`、`test_resume_share.py`、`test_resume_pdf.py`、模板管理与迁移测试，前端 `ResumeWorkbench`、`resumeStore`、`resumeContract`、打印、模板和分享测试，以及 Worker/导入服务单元测试。视觉模板目录测试直接读取 `0070–0076`、`0078–0081` 的 SQL 模板快照，并按 Atlas、Studio、Open、Original、Career、Featured 的主题清单核对模板身份与打印渲染；迁移重编号时必须同步这些测试输入。

## Muse 模板目录

迁移 `0100` 追加 79 套 `muse-*` 模板；`0104` 下架其中 14 套近似版式，保留 65 套代表款，默认启用目录为 150 套。原有 85 套模板保持不变。新增保留款按版式归组排序，并补充既有风格和场景标签；管理员排序和分类的保护规则及逐套清单见[模板目录整理](resume-template-curation.md)。通用模板复用现有虚构产品经理样本，行业模板使用各自虚构样本；内容进入现有 canonical 编辑、自动保存、切换、分享和 PDF 链路。需要系统占位头像时统一显示戴耳机猫咪，保持图像比例并居中适配头像框；历史内置 PNG/SVG 头像资源同步使用这张图，真实上传照片沿用原有展示方式。默认自然分页，不自动缩字或启用智能一页。适配边界与逐套来源见[模板来源](../internals/resume-template-sources.md#muse-选择集0100)。


## 账号能力与客户端边界

普通 Web 的编辑器、工具栏、模板筛选和分享 UI 支持账号界面语言；简历正文、模板样例与用户输入保持原文。注销受理后拒绝新写入，公开分享同时核对所有者仍为启用账号。见[账号功能](identity-account.md)和[Web 语言边界](../internals/web.md#普通工作区界面语言)。
