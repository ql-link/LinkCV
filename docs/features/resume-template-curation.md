# Muse 模板目录整理

迁移 `0104` 将新增 Muse 系列中重复度很高的 14 套版式下架，保留 65 套代表款。原有 85 套启用模板的记录和排序不变，默认可选目录为 150 套。比较以实际排版为准：相同身份区、主辅栏和章节层级，仅配色、联系方式对齐或细线装饰变化的款式归并；工牌、线圈、图框、数字锚点等独立结构保留。

下架只设置 `is_active=0`，不删除模板 ID、正文、定义或用户简历。已有简历仍使用自己的模板快照，编辑、分享和 PDF 继续识别全部 79 个 Muse 主题。普通模板目录、创建和切换入口沿用既有启用校验。

## 展示顺序与标签

原有模板保持原位；新增模板按以下顺序归组。此分组只决定目录排序，不增加新的筛选枚举。每套保留款补充现有的「简约 / 经典 / 现代 / 创意」风格标签，以及「实习 / 校招 / 社招」适用场景，可从模板页和编辑器模板筛选入口使用。

- **清爽履历**：纤线留白、双线年华、银灰方影、灰羽侧记、雾青圆章、目录书签、岁月年谱、数字锚点、彩页侧签、斜月时序。
- **肖像与侧栏**：蓝笺工牌、深蓝叠影、蓝锋斜角、青影错位、拾光相纸、琥珀柔光、暮砂圆影、炭灰方章、黑幕手写、三叠姓名牌、书脊竖韵、昼夜之间、墨粒纹理、折角灰笺。
- **手账与色彩**：春日来信、金黄手记、线圈相簿、蓝瓷纸纹、珊红絮语、青蓝转角、晴空弧线、珊瑚粉笺、绛霞大字、青岚水彩、赭红斜影、酒红书纹、紫霭渐层、墨夜大字、鼠尾草花笺、十字构图、月门留影、虹光梦境、丹红双栏、赤红编年、夜航代码、夜蓝金边。
- **行业专题**：建筑蓝图、梁间图签、金衡交易簿、远见研报、墨线底稿、法律备忘录、法理札记、晶芯规格书、迭代修订簿、杏林学术、白衣行路、页边批注、青衿育人、风起新闻、声色节目单、知微实验簿、元素微光、幕间场刊、观澜策论。

## 存量保护

迁移按 79 个已知 key 和完整种子定义限定范围；自定义定义、其他模板和上传项不修改。只有全套 Muse 目录仍保持 `0100` 的原始排序时才归组，已被管理员调整的顺序整体保留；新增排序放在其他模板最大排序值之后，沿用 1000000 上限。只有启用且标签完全为空、审核为 `pending` 的保留款补初始分类；已分类、待讨论或局部填写的标签均保留，停用款不重新启用。重复执行不重置后续管理员排序与分类。

目录和样式不需要同步删减：下架款式的渲染代码、来源记录和名称对照仍保留以支持历史快照。恢复可通过既有管理入口或新的向前迁移，不能改写 `0104` 或执行 downgrade。原型与来源见[模板来源](../internals/resume-template-sources.md#muse-选择集0100)，全部名称见[名称对照](resume-template-names.md)。
