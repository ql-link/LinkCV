# LinkCV AI 工作流改造施工记录

## 1. 身份与边界

| 项目 | 当前值 |
| --- | --- |
| 性质 | 临时、受 Git 管理的分支施工记录 |
| 适用分支 | `refactor/local-ai-workflow-redesign` |
| 起始基线 | `b13a70d53d885c8f9dd93c3de28df16a53e7a380`（当时的 `origin/dev`） |
| 建立日期 | 2026-08-01 |
| 当前状态 | 阶段 1、阶段 2 已完成；阶段 3 已按“删除机器状态、保留 Spec 中心”实施，完整验证通过，独立复核问题已修正 |
| 最终处理 | 改造收口时删除本目录，并删除项目入口中的临时指针 |

本目录解决一个问题：改造会跨多个会话和多个步骤，不能只依赖聊天记录恢复上下文。

本目录**不是现行 AI 工作流的权威来源**。在某项改造尚未由代码、测试和正式项目规则共同落地前，当前有效行为仍以以下内容为准：

1. 真实代码与测试；
2. `AGENTS.md`（实际内容来自 `.ai/prompts/project.md`）；
3. `.ai/skills/` 中的现有 Skill；
4. `.specs/README.md` 与其他当前项目文档；
5. 真实可执行的质量脚本和测试。

如果本目录与上述内容冲突，应把冲突记录到 `decisions.md` 或 `progress.md`，不能直接把计划中的行为当成已经生效。

## 2. 文件索引

| 文件 | 作用 | 什么时候更新 |
| --- | --- | --- |
| [analysis.md](analysis.md) | 保存来源、仓库现状、已确认问题、可保留能力和改造约束 | 基线变化或发现新的仓库事实时 |
| [plan.md](plan.md) | 保存分阶段工作计划、每阶段完成条件和验证要求 | 范围、顺序或阶段目标变化时 |
| [workflow-model.md](workflow-model.md) | 保存已确认的七维判断、Spec 中心执行方式，以及仍属候选的外部收尾模型 | 维度、映射、产物或收尾设计变化时 |
| [cross-session-records.md](cross-session-records.md) | 保存已确认的无状态跨会话恢复、工作树复制边界和收尾方式 | 跨会话记录职责或生命周期变化时 |
| [phase-1-plan.md](phase-1-plan.md) | 保存已暂停的“新增最小 Change 工具”候选，防止重复走回该方向 | 只在重新评估该方向时 |
| [decisions.md](decisions.md) | 保存已确认、待确认、已替代和已撤回的关键决定或候选 | 每次关键决定确认后立即更新 |
| [progress.md](progress.md) | 保存当前进度、实际改动、验证结果、阻塞和下一步 | 每个可验证小步结束或会话交接前 |

推荐恢复顺序：

1. 先读本文件确认边界；
2. 读 `progress.md` 知道做到哪里；
3. 读 `decisions.md` 确认当前有效决定；
4. 读 `workflow-model.md` 了解正在讨论的目标模型；
5. 涉及恢复和记录机制时读 `cross-session-records.md`；
6. 按当前阶段读取 `plan.md`；`phase-1-plan.md` 只用于查看已否决的 Change 双轨方向，不能作为施工依据；
7. 按需读 `analysis.md`；
8. 再核对相关代码、测试和正式规则，不只凭施工记录继续修改。

## 3. 记录规则

- 只记录可交接的事实、决定、结果、风险和下一步，不保存私有推理过程或大段调试流水账。
- “计划完成”不等于“已经实现”。只有真实代码、对应测试和正式规则同步完成，才可以在 `progress.md` 中标为已完成。
- 已确认决定使用稳定编号；已生效决定被替代时标为“已替代”，从未生效的候选被新方向取代时标为“已撤回”，不直接删除历史。
- 实际执行的验证命令、结果和未覆盖范围写入 `progress.md`，不得把准备执行写成已经通过。
- 两篇输入文档只作为分析来源，不直接成为现行项目规则；本目录保留其摘要和内容哈希，避免依赖 Downloads 目录才能恢复核心结论。
- 不记录密钥、真实用户数据、访问令牌、私密文档原文或不必要的个人信息。
- 普通业务任务仍按当时已经生效的项目规则处理；本次工作流改造使用项目允许的自举例外，但不跳过 Git 安全、真实验证和审查底线。

## 4. 收口与删除条件

只有同时满足以下条件，才能删除本目录：

- 已确认范围全部实现，或未实现部分已明确移出本次改造；
- 已确认没有旧任务需要迁移，废弃状态工具和兼容规则已经删除；
- 受影响的项目入口、Skill、模板、脚本、测试和长期文档已经同步；
- 完整质量检查通过，或阻塞项和风险已得到用户明确处理；
- `decisions.md` 中没有影响交付的待确认项；
- `progress.md` 中没有未同步的实现事实或验证结果；
- 项目入口中的临时分支提示已删除；
- PR 不依赖本目录才能理解最终系统如何工作。

删除后，必要的长期事实进入正式项目文档；一次性的分析、计划和施工过程只保留在 Git 历史及 PR 中。
