# LinkCV 微信小程序

这是可独立导入微信开发者工具的原生小程序工程。运行时只依赖已部署的 LinkCV FastAPI 服务，不依赖 Web 前端工程。

## 已实现范围

- 冷启动直接进入游客首页：展示 LinkCV 功能介绍、示例简历预览和登录入口，全程不要求登录、不弹任何授权、不识别微信身份、不发起任何认证请求。底部提供"首页 / 我的简历"两个标签页。
- 登录是用户主动行为：用户点击首页或"我的简历"引导态的登录入口后进入登录页；登录页先用当前微信临时 code 只读判断是否已有 LinkCV 账号，并分别展示"同意并登录"或"同意并注册"。用户查看并勾选小程序隐私保护指引、主动点击注册后，才允许创建普通账号；后端也会拒绝未携带确认标记的首次建号请求。登录页始终提供"暂不登录"，可返回游客首页。
- "我的简历"页未登录时展示可返回的登录引导，不强制跳转登录页；会话失效且静默恢复失败时也回到该引导态。恢复链只尝试登录已有账号，不会静默注册。
- 扫描 LinkCV 网页小程序码后由首页转交进入独立的网页登录确认页；未同意隐私指引时不能确认网页登录，用户可取消本次登录并返回首页。
- 登录后只读查看本人简历列表和详情。
- 小程序使用 Bearer access token 和轮换 refresh token；不接收 Web Cookie。
- 不提供简历创建、编辑、删除、导出、分享、账号绑定或管理员入口。

以上"游客先浏览、登录可取消"的交互顺序是为满足微信平台"未浏览体验功能服务前不得要求授权登录"的审核要求而设计的；整改依据与验收场景见 `.specs/LOCAL-20260823-miniprogram-guest-first/`。

## 导入开发者工具

1. 打开微信开发者工具，选择"导入项目"。
2. 项目目录选择本目录 `apps/miniprogram`，不要选择仓库根目录。
3. AppID 使用 `project.config.json` 中的项目 AppID；如果实际发布主体不同，先替换为该主体的小程序 AppID。
4. 开发版默认访问 `http://127.0.0.1:8000`。后端在其他内网地址时，在开发者工具控制台执行 `wx.setStorageSync("linkcv_api_base_url", "http://<内网地址>:8000")`，重新进入小程序即可；该覆盖只在 `develop` 生效，不需要修改受版本控制的文件。开发者工具中还需临时关闭"校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"。
5. 在微信公众平台配置并发布"小程序用户隐私保护指引"；启动后端并配置与小程序 AppID 配对的 `WECHAT_APPID` 和 `WECHAT_SECRET`，再测试游客首页浏览、登录/注册、扫码确认和简历读取。

## 体验版与正式版

`config/runtime.js` 已按运行环境拆分地址：

```js
module.exports = {
  developmentApiBaseUrl: "http://127.0.0.1:8000",
  productionApiBaseUrl: "https://linkresume.cn",
};
```

该地址是小程序包内公开的 API 根地址，不是密钥。体验版和正式版忽略开发者工具中的本地存储覆盖，并拒绝 HTTP 地址。通过第三方平台代开发时也可以用 ext config 的 `apiBaseUrl` 覆盖默认地址；普通开发者工具联调优先使用上面的本地存储方式。`WECHAT_SECRET` 只能保存在后端私密环境中，禁止写入本目录。

还必须在微信公众平台完成：

1. 把 `https://linkresume.cn` 登记为 request 合法域名，并保证公网 HTTPS 证书有效。
2. 确认后端 `WECHAT_APPID/WECHAT_SECRET` 与待发布小程序完全匹配。
3. 配置小程序名称、图标、服务类目并发布用户隐私保护指引；当前客户端使用微信原生 `wx.openPrivacyContract` 展示该指引，不包含自建协议页面。
4. 上传体验版，使用真实微信先验证合规交互：冷启动不出现任何授权弹窗、游客可完整浏览首页、未登录的"我的简历"只显示可返回的引导；再验证用户主动登录或注册（未勾选时不能建号）、扫码确认、扫码取消、会话续期、本人简历和越权详情。
5. 在管理端停用测试普通账号，确认 Web 与小程序会话都立即失效；同时确认管理员仍只能从 Web `/admin/login` 登录。
6. 真机验收通过后再提交微信审核和发布。

完整人工验收步骤见 `.specs/LOCAL-20260823-miniprogram-guest-first/`（含 `solution.md` 方案与 `acceptance.feature` 验收契约；提审前按契约完成人工场景）。

## 本地自动化测试

在仓库根目录运行：

```bash
npm run test:miniprogram
```

这些测试覆盖运行环境配置、游客首页零认证请求与扫码转交、隐私同意门禁、登录页主动进入与暂不登录、未登录引导态、token 续期并发与失败行为，以及简历只读映射；它们不能替代微信开发者工具和真机验收。
