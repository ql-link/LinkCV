# 前端原型

本技能只回答一个问题：某个尚未确定的前端结果应该长什么样。原型是用于决策的临时视觉材料，不是所有前端开发的前置阶段。

## 何时使用

- 用户明确要求原型、视觉方案或 Figma 设计；
- 新页面、主要区域或视觉重做存在真实设计分支，仅靠文字难以确定；
- 当前实现暴露出信息层级、状态表达或响应式结构问题，需要先比较候选结果。

已有确认设计、改动范围明确，或只是逻辑、文案、测试和局部样式修复时不要使用。

## 形成原型

先读取目标路由、相邻页面、现有业务组件、`apps/web/DESIGN.md`、Token 和真实数据形状，只获取回答当前视觉问题所需的上下文。

根据问题选择最轻的产物：

- 快速讨论视觉方向时生成原型图；
- 用户需要编辑、逐项审阅或长期保留时写入其指定的 Figma；
- 用户已经给出可用视觉材料时直接在该材料上迭代，不重复生成另一份来源。

候选方案必须遵守 LinkCV 已有组件、字体角色、色彩、间距和布局尺度。需要比较时提供少量结构上真正不同的候选，不用换颜色或装饰制造虚假差异。原型只表现当前决策需要的主要状态和断点，不补齐整套产品稿，也不虚构真实 API 不支持的核心行为。

## 结束条件

向用户展示可访问的产物，说明它回答的问题、采用的项目约束和仍待决定的差异。用户确认的结果或最新反馈成为后续实现的视觉依据；本技能本身不修改生产页面、不运行交付检查，也不指定下一项能力。
