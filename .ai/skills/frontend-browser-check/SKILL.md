# 前端浏览器检查

本技能用真实浏览器回答一个具体的运行时问题。它可以在实现完成后使用，也可以在调查页面行为时单独使用，不是每次前端修改的固定收尾阶段。

## 确定检查范围

从用户请求、实际改动和目标路由提取需要观察的行为。只覆盖本次问题真正涉及的交互、状态和视口，不套用固定页面清单，也不因为打开了浏览器就扩展成全站验收。

需要启动本地服务时，按用户要连接的中间件选择 `npm run dev:local` 或 `npm run dev:development`，并核对实际地址和连通性。复用项目已有测试数据和虚构输入，不录入真实简历、联系方式或凭据。

## 执行与记录

- 打开真实消费路由，不用隔离组件页面代替业务页面；
- 执行能证明目标行为的最少操作，观察页面、控制台和必要的网络结果；
- 只在响应式行为属于本次问题时检查相关窄、中或宽视口；
- 发现阻塞时保留可复现步骤和可见现象，不根据猜测宣称原因；
- 不创建截图基线、人工验收文件或新的自动化 E2E，除非用户另有明确要求。

最终报告实际环境、路由、操作、观察结果和未覆盖项。检查发现的问题是否立即修正，由当前任务授权和范围决定；本技能不指定后续流程。
